# SIGNALBOUND

A standalone browser action-adventure with Physical and Signal layers.

[Play SIGNALBOUND](https://skabkleveta-creator.github.io/skab-digital-reality-arcade/games/signalbound/) · [Visit the arcade](https://skabkleveta-creator.github.io/skab-digital-reality-arcade/)

Open `index.html` in a modern browser, or serve this directory using a static web server. The game includes its graphics, music, and sound synthesis in one file. No external assets or build step are required.

## Controls

WASD/arrows move; J/Z strikes and interacts (hold to charge); K/X rolls; L/V guards; I/C fires a pulse; Space/Shift changes layers; U/F uses a Signal tool; Q/E swaps tools; M opens the map; Esc pauses. Touch controls and gamepads are supported. Progress saves in the current browser.
